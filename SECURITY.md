# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x (latest minor) | Yes |
| &lt; 1.0 | No |

## Reporting a vulnerability

Do not open public issues for security problems. When the GitHub repo exists, use
[Private Vulnerability Reporting](https://github.com/curentis/openfga-php/security/advisories/new)
or email **&lt;SECURITY_EMAIL&gt;** (replace before public launch).
